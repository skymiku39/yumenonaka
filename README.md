# 中之夢　試玩原型

《中之夢》（Yumenonaka）的規則原型：一季四週。用來試機制和遊玩流程，數字都是佔位，劇情與台詞是暫代文字。

規則的依據是設計工作區的 `docs/03-玩法規格.md`（在上一層目錄，不在這個 repo 裡）。

## 怎麼玩

用瀏覽器打開 `index.html` 就可以，不需要安裝任何東西，也不需要伺服器。

一週的流程：

1. **排行程**：先決定這週直播播什麼，再把行動放進週曆，然後開始。
2. **過日子**：一天一天看結果。每天睡前可以選擇繼續，或隔天早上回週曆改行程。
3. **直播日**：開播後你變成聊天室裡的一位草民。每一段先出現一幕，再輪到你選一件事；你的留言會決定她怎麼接。
4. **回看日**：回到奈實，決定昨晚的真心片段要留下還是剪掉。

一季的流程：開場選擅長的路線，再選季初方針（專心一條路線、放下一件事）。四個關鍵週之間各有一段蒙太奇，選一個重心一次帶過三週。第 2 週後與第 4 週後各有一場夢，第 3 週開頭有一通家裡的電話。第 2、3 週開始時如果壓力撐不住，那一週會變成「撐不住的一週」，可以休播。

操作：

| 操作 | 作用 |
|---|---|
| 點行動小卡，再點週曆的格子 | 把行動放上去；再點一次同樣的格子可以拿掉 |
| 點日子的標題 | 用手上的行動把那天的空格填滿 |
| 滑鼠停在小卡或格子上 | 上方會動到的數值、對應的時段與日子會閃 |
| 空白鍵、Enter | 只有一顆按鈕時前進 |
| 數字鍵 1–9 | 選第幾個選項（排行程的畫面除外） |

進度存在瀏覽器的 localStorage，下次打開可以從最近一次排行程的地方接著玩。

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html` | 只有一個掛載點 |
| `main.js` | 全部的規則與畫面。開頭是貼紙圖與資料表，接著是行動規則、畫面、排行程、直播、回看、結算 |
| `style.css` | 樣式。房間的四個時段在 `.scene.t0`–`.scene.t3` |

`main.js` 裡比較常會改的地方：

| 想改什麼 | 找哪裡 |
|---|---|
| 金額（台幣） | `PAY` |
| 靈感的數字 | `INSP` |
| 休息的方式 | `REST` |
| 研習開在哪幾天、哪些時段不能排 | `STUDY_DAYS`、`allowed()` |
| 每個行動的效果 | `step()`。排程的預估和實際執行共用這一個函式 |
| 直播的提問與台詞 | `PROMPTS`、`ROUTES` |
| 技能樹的節點名稱 | `NODES` |
| 到新階段的劇情 | `story()` |
| 設備 | `GEAR` |
| 笑聲三階段、說不出口的程度 | `LAUGH`、`laughOf()`、`voiceLv()`、`sayable()` |
| 被認得的門檻 | `FAME`、`fameOf()` |
| 接不接得住她 | `resolve()` 開頭的 A1 那段 |
| 季初方針、專心與非專心路線的練習次數 | `policy()`、`letgoPick()`、`need()` |
| 蒙太奇的重心 | `MONTAGE`、`montage()` |
| 撐不住的一週、休播 | `nextWeek()`、`G.crisis`、`G.offLive` |
| 家人電話 | `familyCall()` |

## 測試用的網址參數

加在 `index.html` 後面，例如 `index.html?auto&seed=3`。

| 參數 | 作用 |
|---|---|
| `auto` | 隨機排行程、隨機點選，一路玩到結算。成功時分頁標題變成 `AUTO-DONE`，出錯時變成 `ERR ...` |
| `stop=plan`（或 `day`、`night`、`dream`、`mini`、`story`） | 搭配 `auto`，停在第一次出現的那種畫面 |
| `after=數字` | 搭配 `stop`（`story` 除外），在那種畫面上多等幾次檢查才停。數字越大停得越晚，不是精確的「第幾次出現」 |
| `seed=數字` | 固定亂數，同樣的操作每次結果相同 |
| `mini` | 搭配 `auto`，會真的進找靈感小遊戲 |
| `freeze` | 小遊戲不倒數（截圖用） |
| `tree` | 一開始就打開技能樹 |
| `ai` | 開啟 AI 留言評分：直播時可以自己打留言，由瀏覽器裡的小型語言模型判斷語氣。第一次要下載約 1 GB，需要 WebGPU |
| `ai=rule` | 同上，但只用關鍵字規則評分，不下載模型 |
| `model=名稱` | 換 AI 留言評分用的模型 |

帶 `auto` 或 `seed` 時不會讀寫、也不會清除存檔（再加 `forcesave` 可以強制開啟，測存檔用）。

## 操作測試

`test/harness.html` 會把遊戲放進一個框裡，照 `test/scripts.js` 的腳本一步一步點按鈕，最後把畫面文字和遊戲狀態印在下方。和 `auto` 的亂點不同，腳本是固定的，適合在改規則之後確認「照目標玩還能不能玩完一季」。

瀏覽器不允許本機檔案互相讀取，所以要先在這個資料夾開一個本機伺服器：

```bash
python -m http.server 8000
```

然後打開 `http://localhost:8000/test/harness.html?s=full`。`s` 是腳本名稱，打錯時頁面會列出全部可用的名稱。

| 腳本 | 內容 |
|---|---|
| `full` | 照目標玩完一季：練習、研習、準備直播、直播時接住她、回看時留下。結束時應該四個目標都達成 |
| `perfect` | 每次都要她維持人設 |
| `lazy` | 什麼都不排 |
| `overwork` | 不休息，只上班、練習、準備直播 |
| `tipper` | 每一段都給大額 SC |
| `wish` | 只許願，整週看電影 |
| `spender` | 整週出門吃好料，看錢花光會怎樣 |
| `plan1`、`day1`、`stream`、`review`、`dream`、`tree`、`exam` 等 | 照目標玩，停在那個畫面（看版面用） |
| `save`、`save2` | 存檔後重新整理再讀回來（網址要多帶 `extra=forcesave`） |
| `late3` | 先在 ① 留下兩段，之後才練到 ②：當天就要升到 ③ |
| `grey` | 壓力撐不住的隔天排了上午到下午的班：上午那格顯示「起不來」，下午那格要顯示「沒趕上」 |
| `minikeys` | 小遊戲進行中按數字鍵不能有反應 |
| `fillday` | 點日子的標題填滿整天；研習日以外填不進研習 |
| `crisis` | 第 1 週結束時壓力撐不住：第 2 週週一整天起不來，選休播後直播日不開台 |
| `catch` | 緊繃時第一次接住她會接不住、第二次接得住；撐不住時接不住，但壓力會降 |
| `call` | 沒留下過片段時，家人電話的「最近有點累」「其實我有在直播」都被劃掉 |
| `gear` | 買新麥克風：錢扣掉、設備記下來 |

其他網址參數：`seed`（亂數種子，預設 7）、`w`、`h`（遊戲視窗的寬高）、`extra`（要多帶給遊戲的參數）。
