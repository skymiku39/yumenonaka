# 中之夢 v0.1

《中之夢》（Yumenonaka）的可玩版本 v0.1。分成三個頁面：「一季」（四週）、「第一年」（四季、16 個關鍵週，到畢業為止）、「三年」（十二季，第三年最後一場決定結局），首頁選一個進去。三個頁面共用同一支程式，存檔分開。機制照設計文件定案的做法（03 的 4.17），數字都是佔位，劇情與台詞是暫代文字。

規則的依據是設計工作區的 `docs/03-玩法規格.md`（在上一層目錄，不在這個 repo 裡）。

## 怎麼玩

線上版：<https://skymiku39.github.io/yumenonaka/>（GitHub Pages，`main` 分支更新後幾分鐘內跟著更新）。

本機：用瀏覽器打開 `index.html`（首頁）就可以，不需要安裝任何東西，也不需要伺服器。也可以直接打開 `season.html`、`year.html`、`three.html`。

一週的流程：

1. **排行程**：點週曆上「直播」那一格決定這週播什麼，再把右邊的行動放進週曆，然後按右下角的「開始這一週」。
2. **過日子**：一天一天看結果。每天睡前可以選擇繼續，或隔天早上回週曆改行程。
3. **直播日**：開播後你變成聊天室裡的一位草民。每一段先出現一幕，再輪到你選一件事；你的留言會決定她怎麼接。說話的選項在聊天室下面，打賞和許願在直播畫面下面。
4. **下播後**：回到奈實，在回放公開前決定今晚的真心片段要留下還是剪掉。畫面是回放的時間軸，旁邊是那一刻的聊天室。之後是今晚剩下的時間，然後週日照週曆過。

練習、研習、找靈感、準備直播要擲骰，週曆格子上寫成功率，過完的格子寫結果。上班和休息一定照計畫。練習的格子有一條進度條（離「② 上手」還差多少），研習的格子寫學習度；靈感和準備寫在直播那一格。

畫面的版面照設計文件 06（介面設計方向）：最上面一列只有日期、心力、壓力、錢和主線倒數；左邊固定有五個選單（技能樹、目標、設備、收藏冊、設定），直播時也在，夢和標題畫面沒有。買設備在「設備」，只有排行程的時候能買。

一季的流程：開場選擅長的路線，再選季初方針（專心一條路線、放下一件事）。四個關鍵週之間各有一段蒙太奇，選一個重心一次帶過三週。第 2 週後與第 4 週後各有一場夢，第 3 週開頭有一通家裡的電話。第 2、3 週開始時如果壓力撐不住（或上週有兩個以上灰色的早晨），那一週會變成「撐不住的一週」，可以休播。每個關鍵週開頭有一件事：第 1 週店長請她代班，第 2 週研習的期中報告，第 3 週家裡的電話。期末之後是「最後一場的那句話」，用和三年版相同的結局規則決定這一季的結局。

第一年版：主線是畢業那通電話（設計文件 05）。最上面一列的右半是主線倒數（一季版與三年版也有）：先是這一季的關卡（第 4 週的季末大企劃，有期末的季再加期末）還有幾週，剩四週以內變紅，當週改寫直播在幾天後；一排格子是到畢業為止的 16 個關鍵週，方格是每季第 4 週，紅框是有期末的季。再來是離那通電話還有幾週。兩個條件收在選單的「目標」：頻道看不看得到路（訂閱數，佔位門檻在 `CHAN`；直播幾乎不賺錢，所以不叫「養得活」，見設計文件 03 的 2.29）、她的笑聲階段。第 4 季末畢業結算之後家裡打來，四種回答看這兩個條件，說不出口的會被劃掉；選完就是尾聲與結算，不再有「最後一場的那句話」。三年版也有這通電話，但只當第一年的結尾，結局仍在第三年。

第一年版：每季開頭重選季初方針、家裡的生活費入帳。第 2 季末考上學期期末（沒過的話，下學期頭兩週有補考），第 4 季末是畢業結算（沒過就延畢）。16 個關鍵週的事件照設計文件 03 的 2.20：代班、期中報告、家人電話、同學聚餐、房東修水管、畢業專題、寫履歷、同學拿到 offer 等。許願解鎖的企劃，她會答應下次播；拖太久會插入「承諾到期」。

三年版：畢業後家裡的生活費停了，每週開銷加上房租；沒有研習，改成偶爾出現的付費工作坊；錢不夠就刷卡，下週一被迫多排一班。年底沒過的話，第二年第一季整季重修，心力上限少 1 格。第三年有「翻出剪掉的片段」與說得出直播的家人電話，最後一季的最後一場直播決定結局。

操作：

| 操作 | 作用 |
|---|---|
| 點行動小卡，再點週曆的格子 | 把行動放上去；再點一次同樣的格子可以拿掉 |
| 點週曆上「直播」那一格 | 打開直播內容的面板：選路線、季末大企劃、混合企劃、這週休播 |
| 點左邊的選單 | 打開技能樹、目標、設備、收藏冊、設定；再點一次、按「關閉」、點面板外面或按 Esc 關掉 |
| 點日子的標題 | 用手上的行動把那天的空格填滿 |
| 滑鼠停在小卡或格子上 | 上方會動到的數值、對應的時段與日子會閃 |
| 空白鍵、Enter | 只有一顆按鈕時前進 |
| 數字鍵 1–9 | 選第幾個選項（排行程的畫面除外）。直播的選項分兩處放，按鈕右下角寫著對應的數字 |

進度存在瀏覽器的 localStorage，三個頁面各存各的，下次打開同一個頁面可以從最近一次排行程的地方接著玩。

## 測試用的網址參數

加在遊戲頁面後面，例如 `season.html?auto&seed=3`、`three.html?q1`。

| 參數 | 作用 |
|---|---|
| `auto` | 隨機排行程、隨機點選，一路玩到結算。成功時分頁標題變成 `AUTO-DONE`，出錯時變成 `ERR ...` |
| `stop=plan`（或 `day`、`night`、`dream`、`mini`、`story`） | 搭配 `auto`，停在第一次出現的那種畫面 |
| `after=數字` | 搭配 `stop`（`story` 除外），在那種畫面上多等幾次檢查才停。數字越大停得越晚，不是精確的「第幾次出現」 |
| `seed=數字` | 固定亂數，同樣的操作每次結果相同 |
| `mini` | 搭配 `auto`，會真的進找靈感小遊戲 |
| `freeze` | 小遊戲不倒數（截圖用） |
| `tree` | 一開始就打開選單的技能樹 |
| `debug` | 設計測試面板，見下面的「設計測試面板」 |
| `ai` | 開啟 AI 留言評分：直播時可以自己打留言，由瀏覽器裡的小型語言模型判斷語氣。第一次要下載約 1 GB，需要 WebGPU |
| `ai=rule` | 同上，但只用關鍵字規則評分，不下載模型 |
| `model=名稱` | 換 AI 留言評分用的模型 |
| `pace` | 比較用：同一條路線一季最多升一層。設計文件 7.7 的 Q5 已定不採用（有能力就可以往後升），預設不受影響 |
| `pace=tree` | 比較用，同上但更嚴：整棵樹一季只升一層 |
| `q1` | 比較用（設計文件 7.5 Q1 的 B，還沒決定）：每季第 3 週的主線大事壓在心上，那一週到直播結束前壓力降不到「緊繃」以下 |
| `q6` | 比較用（7.8 Q6 的 B，還沒決定）：翻出剪掉的資料夾時，「留下其中一段」降成深度 0 |
| `tight` | 比較用（7.6，還沒決定）：最後一場的「謝幕」要主要路線到 ③，或打開過剪掉的資料夾 |

比較用的參數可以一起帶，例如 `?q1&tight`。

帶 `auto`、`seed` 或 `debug` 時不會讀寫、也不會清除存檔（再加 `forcesave` 可以強制開啟，測存檔用）。

## 設計測試面板

網址加 `debug`（例如 `year.html?debug`，首頁最下面也有連結），左下角會出現「設計測試」按鈕（右下角留給往下走的按鈕），按一下或按 `` ` `` 鍵打開。可以和其他參數一起帶，例如 `year.html?debug&q1&seed=3`。

| 區塊 | 作用 |
|---|---|
| 跳到 | 選季、週、畫面後按「跳轉」。畫面有：這一週的開頭（事件）、排行程、排行程的直播內容面板、選單的五個分頁（技能樹、目標、設備、收藏冊、設定）、過完週一、下播後三十秒、撐不住的一週、週三（前兩天已過）、直播日傍晚、直播收尾問要不要加長、找靈感小遊戲、直播開場、回放編輯、週末結算、蒙太奇、短夢、季末夢、期末考、季的總結、季初方針、畢業那通電話、最後一場的那句話、尾聲、結算。還在標題畫面時會自動開一局 |
| 數值 | 心力、壓力、錢、靈感、學習度、準備、訂閱、被認得、留下、剪掉。下面那一行是換算後的階段（壓力、笑聲、認得、頻道、說得出口的程度） |
| 路線與方針 | 四條路線各自的階段、專心、放下、期末結果、家裡知不知道 |
| 套用／套用並重新跳轉 | 「套用」只改數值、重畫現在的畫面，已經出現的選項不會重算；要看數值對選項的影響（例如哪一句被劃掉），用「套用並重新跳轉」 |
| 整包狀態（JSON） | 「讀出現在的狀態」把整個 `G` 轉成文字，可以存起來；貼回去按「套用這段 JSON」會回到那個狀態的排行程畫面 |

跳轉只改季、週和當週的暫存狀態（拿不掉的格子、期限、撐不住等會重設），其他數值不動。所以直接跳到第 3 年時，技能、錢、訂閱還是原本的，要自己在面板上改，或貼一段存好的 JSON。

程式在 `main.js` 最後的「設計測試面板」：要加新的跳轉位置，在 `DBG_GO` 加一項；要加新的數值欄位，在 `DBG_NUM` 加一項。

## 操作測試

**一次跑全部**：`test/run.py` 會自己開本機伺服器、用無頭模式的 Chrome（或 Edge）跑 `test/scripts.js` 的每一支腳本，最後列出失敗的。只用 Python 標準函式庫。

```powershell
python "Y:\薰草\game\test\run.py"
```

預設不跑三年的腳本（`z` 開頭，一支要幾分鐘）；加 `--all` 一起跑，或在後面寫腳本名稱只跑那幾支，例如 `python "Y:\薰草\game\test\run.py" full mix`。有失敗時結束代碼是 1。找不到瀏覽器時，用環境變數 `CHROME` 指定執行檔路徑。

比較還沒決定的選項時，用 `--extra` 把上面的比較用參數帶給每一支腳本，`--wide` 讓統計那一行完整印出來：

```powershell
python "Y:\薰草\game\test\run.py" full carer cutter --extra "q1&tight" --wide
```

**在瀏覽器裡看一支腳本跑**：線上版直接打開 <https://skymiku39.github.io/yumenonaka/test/harness.html?s=full>（`s` 換成腳本名稱）。腳本會自動開對的頁面：`y` 開頭用 `year.html`、`z` 開頭用 `three.html`，其餘用 `season.html`；要指定的話加 `page=year` 之類的參數。本機的話，瀏覽器不允許本機檔案互相讀取，要先開一個本機伺服器，步驟在下面。

`test/harness.html` 會把遊戲放進一個框裡，照 `test/scripts.js` 的腳本一步一步點按鈕，最後把畫面文字和遊戲狀態印在下方。和 `auto` 的亂點不同，腳本是固定的，適合在改規則之後確認「照目標玩還能不能玩完一季」。

腳本靠按鈕上的文字找按鈕，所以改畫面時要留意幾件事：`body` 的 class 一律等於畫面的模式（`plan`、`day`、`night`、`dream`、`mini`、`title`），不要多加；左邊的選單在 DOM 裡排在內容後面，直播的聊天室排在直播畫面前面，這樣畫面上的第一顆按鈕才是第一個選項；畫面標題要留在 `.menu h3`。直播內容要用腳本裡的 `show()`（點直播那一格、在面板裡選、關掉）。

瀏覽器不允許本機檔案互相讀取，所以要先在這個資料夾開一個本機伺服器：

```bash
python -m http.server 8000
```

然後打開 `http://localhost:8000/test/harness.html?s=full`。`s` 是腳本名稱，打錯時頁面會列出全部可用的名稱。

不同玩法的腳本結束時會印一行統計（`G.stat`、結局、理想中的薰草的方向），設計文件第 7 節的分析就是用這些數字。

| 腳本 | 內容 |
|---|---|
| `full` | 照目標玩完一季：練習、研習、準備直播、直播時接住她、回放編輯時留下。結束時應該四個目標都達成 |
| `perfect` | 每次都要她維持人設 |
| `lazy` | 什麼都不排 |
| `overwork` | 不休息，只上班、練習、準備直播 |
| `tipper` | 每一段都給大額 SC |
| `wish` | 只許願，整週看電影 |
| `spender` | 整週出門吃好料，看錢花光會怎樣 |
| `carer` | 照目標玩，每段都接住她、全部留下 |
| `cutter`、`curtain` | 照目標玩，但全部剪掉；`curtain` 最後一場選謝幕 |
| `grinder` | 每天都練習，放下研習 |
| `worker` | 每天上午上班，直播全部沉默 |
| `yfull`、`yrotate`、`ycutter`、`ylazy`、`yoverwork`、`ywish` | 第一年模式的六種玩法（`yrotate` 每季換一條專心的路線） |
| `zfull`、`zcutter`、`zlazy` | 三年模式的三種玩法。很長，用無頭瀏覽器跑時要把虛擬時間調大 |
| `plan1`、`day1`、`stream`、`review`、`dream`、`tree`、`exam` 等 | 照目標玩，停在那個畫面（看版面用） |
| `save`、`save2` | 存檔後重新整理再讀回來（網址要多帶 `extra=forcesave`） |
| `late3` | 先在 ① 留下兩段，之後才練到 ②：當天就要升到 ③ |
| `grey` | 壓力撐不住的隔天排了上午到下午的班：上午那格顯示「起不來」，下午那格要顯示「沒趕上」 |
| `minikeys` | 小遊戲進行中按數字鍵不能有反應 |
| `fillday` | 點日子的標題填滿整天；研習日以外填不進研習 |
| `crisis` | 第 1 週結束時壓力撐不住：第 2 週週一整天起不來，選休播後直播日不開台 |
| `catch` | 緊繃時第一次接住她會接不住、第二次接得住；撐不住時接不住，但壓力會降 |
| `call` | 沒留下過片段時，家人電話的「最近有點累」「其實我有在直播」都被劃掉 |
| `gear` | 買新麥克風：錢扣掉、設備記下來 |
| `copylog` | 結算的「複製這局的紀錄」：有結算、統計、每週一行 |
| `epilogue`、`epicut` | 結局後的四張尾聲卡（留下的玩家、剪掉的玩家） |
| `mix` | 混合企劃：能勾、直播標題、留下時兩條路線都算 |
| `weigh` | 帶 `q1`：照顧得好的玩家（carer），第 3 週也會緊繃到直播 |
| `tightend` | 帶 `tight`：一直剪掉的玩家一季拿不到謝幕 |
| `dig`、`q6dig` | 剪掉的資料夾：沒留下過的玩家，「留下其中一段」預設說不出口；帶 `q6` 時說得出口 |

`run.py` 會自動替 `save`、`save2`、`weigh`、`tightend`、`q6dig` 帶上需要的參數；在瀏覽器裡看時要自己加，例如 `harness.html?s=weigh&extra=q1`。

其他網址參數：`seed`（亂數種子，預設 7）、`w`、`h`（遊戲視窗的寬高）、`extra`（要多帶給遊戲的參數）。
